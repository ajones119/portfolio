How EventEmitter Works

Lesson 1 · Three.js Experience Architecture · Cheatsheet · Mission

The one-sentence version

EventEmitter is a message board inside a class. Other parts of your app can subscribe (on) and get called when that class broadcasts (trigger) — without importing each other directly.

Your code, right now

Two classes in your project already use this pattern:

// Sizes extends EventEmitter — it CAN broadcast
class Sizes extends EventEmitter {
  resize() {
    this.width = window.innerWidth;
    this.trigger('resize');  // ← broadcast
  }
}

// Experience listens — it CAN subscribe
this.sizes.on('resize', () => {
  console.log('resize');
});

Notice the two layers:

window.addEventListener('resize') ← browser says viewport changed ↓ Sizes.resize() ← your class updates its numbers ↓ this.trigger('resize') ← your class tells the rest of the app ↓ Experience callback runs ← camera / renderer can react
DOM events and EventEmitter are not duplicates. The browser event is the input; trigger is your app’s output to other classes.

What’s stored inside

The constructor creates an empty registry: this.callbacks. Think of it as nested folders of listener functions: 

callbacks = {
  base: {           // "namespace"
    resize: [ fn, fn ],   // event name → array of callbacks
    tick:   [ fn ]
  }
}

on('resize', fn) pushes fn into that array. trigger('resize') loops the array and calls every function. off('resize') deletes the array.

Walk through on

  1. Parse the name string (strip junk, split on spaces for multiple events).
  2. Split event.namespace on the dot — default namespace is base.
  3. Create the namespace bucket and event array if missing.
  4. Push your callback. Return this for chaining.

Walk through trigger

  1. Resolve the event name the same way.
  2. If namespace is base, search every namespace for listeners named resize.
  3. If namespace is specific (e.g. resize.sizes), only fire in that namespace.
  4. Call each listener with callback.apply(this, args) — this inside the listener is the emitter instance (Sizes).
  5. Return the first listener’s return value (rarely used, but supported).

Why extend instead of import?

class Sizes extends EventEmitter means every Sizes instance is an emitter. You write this.trigger(...) naturally — no extra property, no wrapper object. Camera, Renderer, and Time will do the same; Experience wires them together with .on().
