# Atmospheric Three.js Resources

## Knowledge

- [Three.js manual: Lights](https://threejs.org/manual/en/lights.html)
  Official overview of directional and hemisphere lights. Use for: choosing the key light and understanding sky/ground fill.
- [Three.js docs: DirectionalLight](https://threejs.org/docs/pages/DirectionalLight.html)
  API reference for sun-like parallel light, targets, and shadow support. Use for: positioning and aiming the forest sun.
- [Three.js manual: Fog](https://threejs.org/manual/en/fog.html)
  Official explanation of linear and exponential fog, including matching fog and background colors. Use for: atmospheric depth.
- [Three.js docs: Renderer](https://threejs.org/docs/pages/Renderer.html)
  Reference for output color space, tone mapping, exposure, and shadow-map configuration. Use for: final image shaping.
- [Three.js docs: Object3D](https://threejs.org/docs/pages/Object3D.html)
  Reference for `castShadow` and related scene-object behavior. Use for: checking the shadow pipeline end-to-end.

## Wisdom (Communities)

- [Three.js forum](https://discourse.threejs.org/)
  The project’s focused practitioner community. Use for: diagnosing renderer-version quirks and scene-specific shadow artifacts.
